⚖️游戏 AI 功能上线合规工作台

法务场景 · 前端原型

  1. 选一个 AI 功能场景（如「AI 角色陪伴的跨对话记忆」），进入业务事实问卷
  2. 逐题回答产品问题，不确定就选「暂不清楚」——系统把它记为待确认，不替业务方猜答案
  3. 右侧同步生成法务工作底稿：已确认事实、待追问事项、初步关注点
  4. 导出事实确认表，交给产品与研发逐条签字确认

🧱生活积木 Life Blocks

个人工具 · 静态网页

  1. 把一天分成七段，从晨间到睡前，每段放自己要做的具体事
  2. 用三种积木区分事项：方框是必做、圆形是可选、三角是提醒
  3. 顶部进度只统计方框里的必做项，可选的事完成了也不占用分数线
  4. 数据只存在自己浏览器里，可一键导出备份，换设备自己导入

🎁王者荣耀送礼助手

Python 工具 · 本地优先

  1. 给好友建一份档案，写下他最近想要什么
  2. 工具自动识别提到的英雄与皮肤，加入关注
  3. 按四态判定能不能送：可送 / 返场可送 / 不可送 / 待确认，并给出判定依据
  4. 打开「送礼分析」，看现在就能送的皮肤，以及最近一次返场是几天后、还是已经过去几天
